# Deep Learning Weekly - November 24, 2026

Welcome to this week's summary of developments and news in deep learning and machine learning.

## Research Highlights

- **Explainable Machine Learning in Environmental Science**: Researchers used explainable machine learning to reveal how diffuse radiation enhances boreal carbon uptake, providing insights into ecosystem responses to climate factors.
- **Medical Imaging and Diagnostics**: A new CT-based deep learning model has been developed to preoperatively predict microvascular invasion in liver cancer, which could significantly aid in surgical planning and prognosis.
- **Healthcare Risk Prediction**: A study highlighted that machine learning imputation can boost hypertension prediction accuracy but alters clinical risk associations, urging caution in clinical risk modeling.
- **Agricultural and Environmental Modeling**: A machine learning approach effectively predicted soil salinity by combining legacy soil data with Sentinel-2 satellite imagery.
